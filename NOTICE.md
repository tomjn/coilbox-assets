## What is in this repository

Images extracted from third party game and map archives, and images rendered from third party models. Minimaps, buildpics and unit renders.

None of it is original work by coilbox. Nothing in this repository was drawn, photographed or modelled by the project or by anyone working on it.

## Who owns it

Each image remains under the terms its original author set. Those terms differ from file to file and from game to game, and for a great many of them nothing was ever written down.

This repository is a mirror, not a licensor. It cannot give you permission to use any of these images, because it never held that permission to give. If you want to use one, the author is who you ask.

## Asking for something to be removed

If you made something here and you would rather it was not here, say so and it will be taken down. You do not need to explain yourself and you do not need to prove ownership first.

Contact: coilbox@tomjn.com

Say which files, or which game or map they came from, and that is enough to act on. Note that this repository's history is public and permanent, so removing a file removes it from the served site and from the current tree, and rewriting the history it already appears in is a separate and slower request.
